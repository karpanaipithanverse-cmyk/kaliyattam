Kaliyattam
An interactive reading experience

Kaliyattam connects a printed book with digital character artwork and short videos. Readers scan QR codes in the book to reveal a character or watch a video on their phone or tablet.

How it works
1. Find a QR code in the Kaliyattam book.
2. Scan it with a phone or tablet camera.
3. View the character illustration or video in your browser.
The site is built with HTML, CSS, and JavaScript and hosted on GitHub Pages. No app installation is needed.

Website: https://karpanaipithanverse-cmyk.github.io/kaliyattam/
Maintaining printed QR codes
Keep the GitHub Pages site and existing character URLs available after the book is printed. To update an image without replacing its QR code, retain the corresponding URL and filename. Check all links before printing.
